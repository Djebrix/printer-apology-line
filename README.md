One-line apology from an office printer to the people who keep jamming it, feeding it cheap paper, and swearing at it — entered in [The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153) on make.fun.

## The line

> Sorry I jammed on page 47, ate your cheap paper, and blamed the Wi-Fi — in my defence, you hit me first.

## How it works

`main.py` (Python stdlib only) writes exactly that one line to `/output/entry.txt`. It validates the line first: exactly one line, no leading or trailing whitespace, and 1–120 characters. The program is deterministic — every run writes the same bytes.
